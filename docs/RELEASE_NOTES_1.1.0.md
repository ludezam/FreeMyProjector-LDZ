Primeira release pública do FreeMyProjector LDZ, validada em HY300 Magic Cube/TXCZ com Android 12.

- Home com paisagem local, favoritos editáveis e grade de aplicativos.
- Ajustes de conexões, projeção, som, aparência, aplicativos e sistema.
- Preparação por ADB local, preservação da home original e restauração pelo menu.
- Otimização reversível somente para candidatos validados; nenhum app desativado no HY300 testado.
- Panorama instantâneo de memória antes/depois, sem teste de velocidade ou troca de telas durante a medição.
- Seis capturas reais e manual de instalação no README.

Instalação: baixe `FreeMyProjector-LDZ-1.1.0.apk` e siga o README. Para atualizar uma instalação com a mesma assinatura, use `adb install -r`.

O botão Buscar atualizações ainda é uma tela pendente nesta versão. A consulta e o download dentro do app precisam ser implementados; a release e o APK já ficam disponíveis pela API do GitHub.

Pacote: `br.com.ldz.freemyprojector` — versionCode `7` — Android 8.0 ou superior. A compatibilidade dos atalhos de projeção depende do firmware.

O APK publicado é idêntico ao testado no projetor, com nome de arquivo simplificado. Assinatura v2/v3 verificada. Confira o arquivo `SHA256SUMS.txt` para validar o download.
